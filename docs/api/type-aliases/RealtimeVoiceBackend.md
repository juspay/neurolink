# Type Alias: RealtimeVoiceBackend

> **RealtimeVoiceBackend** = `"gemini"` \| `"xai"`

The realtime speech-to-speech model a call runs on: Gemini Live on Vertex
(the default) or xAI Grok Voice through LiveKit's xAI plugin.
