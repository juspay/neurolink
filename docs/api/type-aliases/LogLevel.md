# Type Alias: LogLevel

> **LogLevel** = `"debug"` \| `"info"` \| `"warn"` \| `"error"`

Defined in: [types/utilities.ts:16](https://github.com/mansiverma897993/neurolink/blob/2b1aca22c252cf536a76d9d88df95d715b888328/src/lib/types/utilities.ts#L16)

Represents the available logging severity levels.

- debug: Detailed information for debugging purposes
- info: General information about system operation
- warn: Potential issues that don't prevent operation
- error: Critical issues that may cause failures
