# Function: supportsNativeVideo()

> **supportsNativeVideo**(`provider`, `model?`): `boolean`

Whether `provider` (optionally, running `model`) can be handed raw video
bytes. See [getVideoProviderConfig](getVideoProviderConfig.md) for the Claude-on-Vertex case.
