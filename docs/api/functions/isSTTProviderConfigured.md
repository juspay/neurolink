# Function: isSTTProviderConfigured()

> **isSTTProviderConfigured**(`name`, `credentials?`): `boolean`

Whether a provider can run with these credentials and the environment. The
local engine needs no configuration and always counts. Unknown names are
not configured.

## Parameters

### name

`string`

### credentials?

[`STTCredentials`](../type-aliases/STTCredentials.md)

## Returns

`boolean`
